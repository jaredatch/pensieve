- #180: Read project origins with git’s config syntax through the same tokenizer as the sync repository-format check. Ordinary git-written origins keep their identity keys and need no marker.
  URLs containing escaped quotes or backslashes now use the decoded URL in their key; this accepted key move has no migration. A config git refuses to read now has no remote identity, even if its origin appears before the damaged line, and registration creates a marker. A bare or empty first origin URL also falls through to marker identity.
